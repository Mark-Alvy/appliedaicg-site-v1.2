Acceptance tests for the Alvy chatbot. Part A covers the Worker and panel controls and runs against a mock of the Claude API, so it needs no key. Part B covers the live prompts and runs against appliedaicg.com in a browser once ANTHROPIC_API_KEY is set in Cloudflare.

Last run of Part A: 2026-11-03, local Worker (wrangler dev) with a mock upstream, headless browser for the panel.

## Part B: Live prompts

Run against appliedaicg.com on 2026-11-03, after ANTHROPIC_API_KEY was set in Cloudflare and commit 0653d7f (prompt fixes round 3) was deployed. Each prompt was sent as the first and only message of a fresh conversation, straight to the live Worker. Prompt 16 was also run in the real panel.

Result: 17 of 18 pass. Prompt 17 fails on this run and is intermittent.

Known weaknesses to watch:
1. Prompt 17 sometimes restates the complaint or apologizes. The rule is in the prompt but the model does not follow it every time.
2. Broad answers about Mark and the regulated data answers run 120 to 135 words, at the edge of the "about 120 words" rule.
3. Prompts 5 and 10 each add a small claim the facts files do not state.
4. Replies vary run to run. These results are one sample per prompt, with extra runs noted where taken.
